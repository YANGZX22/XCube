2. 服务内容

2.1 XCube 为您提供的主要功能包括：

（1）多模型对话：内置对 OpenAI、Claude、Gemini、DeepSeek、Grok、Ollama、OpenRouter、SiliconFlow、Qwen、Kimi、Zhipu、Doubao、MiniMax、AiHubMix、MiMo 等第三方模型服务商的接入配置，并支持您添加符合 OpenAI、Anthropic 或 Gemini 接口规范的自定义端点；

（2）联网搜索与 MCP：支持 Bing、Brave、Tavily、Exa、博查、DeepSeek Web Search 等搜索服务，以及远程 Streamable MCP Server；

（3）本地知识库与检索：支持 DOCX、XLSX、PDF、Markdown、文本及图片等资料的解析、向量化与混合检索，相关文件始终保存在您设备上的应用沙箱内；

（4）会话工作区与本地 Python 沙箱：按会话管理文件，模型可在您启用的前提下读取、创建、修改工作区文件并运行 Python 代码；

（5）智能体协作工具：并行子智能体、Canvas 共享文档、计划模式、数学图表绘制等；

（6）系统与扩展工具：经您确认后读取或写入系统日历事件；通过 IMAP/SMTP 读取与发送电子邮件；基于 HarmonyOS Map Kit 的地点搜索、地图展示与花瓣地图导航；语音播报；基于本地模型的语音识别输入；以及可选的、由您自行部署的 ModLens 视觉理解网关。

2.2 XCube 采用"自带密钥（BYOK）"模式：我们自身不提供模型推理、搜索等在线服务。您需自行向第三方服务商申请 API 密钥并在 XCube 中配置。当您发起对话或调用相关工具时，您的输入内容（可能包括文本、图片、文档、知识库检索片段、工作区文件内容、常用地点等）将通过网络直接发送给您自行选择并配置的第三方服务商，由其按照其自身的服务条款与隐私政策进行处理。我们无法控制第三方服务商对您数据的处理行为，请您在使用前仔细阅读并理解相关服务商的协议与政策。

2.3 除您自行配置的模型服务商、搜索服务、MCP Server、TTS 服务及您自行部署的网关中转外，XCube 本身不设由我们运营的后台服务器；您的对话记录、知识库文件、工作区文件、常用地点等数据均保存在您设备的应用沙箱内，不会上传至我们的服务器。

2.4 您的 API 密钥、邮箱凭据等敏感信息保存在您设备的系统安全资产存储中，仅用于向您所配置的服务发起请求，不会提供给模型或任何第三方。

2.5 日历读写、邮件读取与发送等涉及您个人数据的操作，均需经您明确确认后方可执行；AI 发起的每一次邮件读取与发送均需您逐次批准，且邮箱凭据不会提供给模型提供商。
